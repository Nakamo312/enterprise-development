## Лабораторная работа 1: «Классы» - Реализация объектной модели данных и unit-тестов (Поликлинника)

**Описание предметной области**

Реализована объектная модель для медицинской клиники, включающая основные сущности для управления информацией о пациентах, врачах, специализациях и назначениях.

Основные сущности:

•   **Пациент (Patient)** - содержит личные данные, контактную информацию, группу крови и резус-фактор.
•   **Врач (Doctor)** - содержит информацию о специализации, личные данные и стаж.
•   **Специализация (Specialization)**  Содержит строковое наименование специализации.
•   **Приём (Appointment)** -  содержит id пациента, врача, дату и времени приёма, номере кабинета и повторности приёма.

**Выполненные задачи**

**1. Объектная модель данных**

Реализованы четыре основных класса, представляющих ключевые сущности медицинской клиники:

•   `Patient` - содержит метаданные пациента: ID, ФИО, номер паспорта, дату рождения, адрес, контактный телефон, группу крови, пол, резус-фактор.
•   `Doctor` - содержит метаданные врача: ID, ФИО, номер паспорта, год рождения, специализацию, стаж работы.
•   `Specialization` - содержит информацию о специализации врача: ID, наименование.
•   `Appointment` - содержит информацию о приеме: ссылку на пациента, ссылку на врача, дату и время приема, номер кабинета, признак повторного приема.

Использованы типы-перечисления:

•   `BloodGroup` - группы крови (A, B, AB, O).
•   `Gender` - пол (Male, Female).
•   `RhFactor` - резус-фактор (Positive, Negative).

**2. Подготовка тестовых данных**

Создан класс `ClinicFixture`, предоставляющий набор данных для тестирования:

•   15 различных пациентов с ФИО, контактной информацией, группой крови и резус-фактором.
•   12 врачей различных специализаций с указанием стажа работы.
•   5 специализаций (терапевт, хирург и т.д.).
•   30 записей о приемах, распределенных по разным пациентам и врачам, с указанием даты, времени, номера кабинета и признака повторного приема.

**3. Unit-тесты**

Реализовано 5 юнит-тестов с использованием Xunit и Assert для проверки бизнес-запросов:

| Тест                                 | Описание                                                                               |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GetDoctorsExperienceGreater | Возвращает список врачей со стажем работы не менее 10 лет, упорядоченных по ФИО.                                                  |
| GetPatientsByDoctorInfo   | Возвращает список пациентов, посетивших конкретного врача, упорядоченных по ФИО.                                                   |
| GetNumberAppointmentsInfo  | Возвращает количество повторных приемов за последний месяц.                                                         |
| GetPatientsInfo | Возвращает список пациентов старше 30 лет, посетивших более одного врача, упорядоченных по дате рождения.                                           |
| GetAppointmentsInfo   | Возвращает список приемов в текущем месяце в выбранном кабинете.                                                          |

Результат

Разработана объектная модель предметной области «Медицинская Клиника» с комплексом unit-тестов, покрывающих ключевые бизнес-сценарии. Тесты проверяют корректность работы с данными о пациентах, врачах, специализациях и назначениях, а также логику фильтрации и сортировки данных.
